## 1. Разбор новых элементов Python (что мы сегодня использовали и зачем)

Все эти элементы уже работают в твоём `main.py` — разложим по полочкам, за что отвечает каждый:

| Элемент кода | Что делает простыми словами | Зачем нам это в проекте |
|---|---|---|
| `from pyscript import document` | Подключает «мост» от Python к HTML-странице (`document` — это вся твоя веб-страница). | Без этого Python не видит кнопки, заголовки и слайды в `index.html`. |
| `from pyscript.ffi import create_proxy` | Подключает «переводчик» между Python и браузером (JavaScript). | Браузер не умеет напрямую запускать Python-функции. `create_proxy(функция)` упаковывает нашу функцию так, чтобы кнопка могла её вызвать. **Важно:** сохраняем результат в переменную (`p_start = create_proxy(...)`), чтобы Python не удалил переходник из памяти! |
| `document.querySelector("#btn-start")` | Находит **один** элемент на странице по его `id` (знак `#` всегда означает `id`). | Чтобы «дотянуться» до конкретной кнопки или конкретного слайда. |
| `document.querySelectorAll(".screen")` | Находит **сразу все** элементы с классом `screen` (знак `.` означает `class`) и возвращает их списком. | Чтобы одним циклом `for` спрятать сразу все слайды перед тем, как открыть нужный. |
| `.classList.add("hidden")` и `.classList.remove("hidden")` | Добавляет или убирает CSS-класс `hidden` у элемента. | В `style.css` класс `.hidden` имеет правило `display: none;`. Добавили класс — слайд исчез; убрали — появился! |
| `f"#{screen_id}"` | **f-строка** — подставляет значение переменной прямо в текст. | Если передать `screen_id = "slide-3"`, получится строка `"#slide-3"`. Благодаря этому одна функция `show_screen` умеет открывать любой слайд! |
| `def go_to_exam(event):` | Функция-обработчик нажатия. | Параметр `event` (событие клика) браузер передаёт сам, даже если внутри функции мы его не используем — без него будет ошибка. |
| `.addEventListener("click", p_start)` | «Приклеивает» реакцию на клик мышки к найденной кнопке. | Говорит браузеру: «Когда нажмут на эту кнопку, вызови функцию `p_start`». |
| `print("Python готов!")` | Печатает текст в **Консоль браузера** (`Ctrl + Shift + J`). | Удобная проверка для разработчика: если надпись появилась в консоли, значит Python загрузился без ошибок. |

## 2. Конструктор красивых кнопок в `style.css` (собери свой дизайн сама!)

> **Сначала секрет, почему кнопки сейчас серые:**  
> В `style.css` и `index.html` не совпадают названия стилей кнопок. Тебе нужно либо поменять название стиля в `index.html` или в `style.css` создать нове стили под текущее название из `index.html`.

Ниже — набор CSS-свойств и эффектов. Не нужно использовать все сразу: **выбирай те, что нравятся, комбинируй и подбирай свои цвета!**

### 🎨 Цвет, форма и объём
| CSS-свойство | Что делает | Какой интересный эффект даёт |
|---|---|---|
| `background` + `linear-gradient(...)` | Задаёт фон кнопки. Вместо одного цвета можно написать градиент (угол + два цвета, например `135deg, #ff4d94, #8b5cf6`). | Кнопка получает **модный плавный перелив** из одного цвета в другой. |
| `border-radius` | Скругляет углы элемента (в `px`). | `12px` — мягкая современная кнопка; `999px` — стильная **кнопка-капсула** с полностью круглыми краями. |
| `border` + `background: transparent` | Рисует цветную рамку вокруг прозрачной кнопки. | **Кнопка-контур (Ghost)** — смотрится воздушно и минималистично, особенно если заливать её цветом при наведении. |
| `border-bottom` | Задаёт отдельную (более толстую и тёмную) рамку снизу, например `4px solid ...`. | Создаёт **объёмный 3D-эффект** (как кнопки в Duolingo!). |
| `box-shadow` | Добавляет тень (смещение X, смещение Y, размытие, цвет). | Если задать цвет тени в тон кнопке (например, полупрозрачный розовый через `rgba(...)`), получится **эффект неонового свечения**! |
| `padding` и `margin` | `padding` — воздух **внутри** кнопки; `margin` — расстояние **снаружи** между кнопками. | Кнопка становится крупной, удобной для нажатия и не слипается с соседними. |
| `cursor: pointer` | Меняет стрелку мышки на «ручку» при наведении. | Сразу подсказывает пользователю, что на элемент можно нажать. |

### ✨ Оживление и анимация (состояния кнопки)
| Селектор / свойство | Когда срабатывает | Какой эффект можно сделать |
|---|---|---|
| `button:hover` | В момент, когда **наводишь мышку** на кнопку. | Поменять цвет фона, усилить `box-shadow` или слегка **приподнять кнопку вверх** через `transform: translateY(-2px)`. |
| `button:active` | В саму долю секунды **нажатия** на кнопку. | **Эффект «вдавливания»**: чуть опустить кнопку (`transform: translateY(2px)`) или слегка уменьшить (`transform: scale(0.97)`). В паре с `border-bottom` ощущается как настоящая физическая кнопка! |
| `transition` | Задаёт плавность изменений (например, `all 0.2s ease`). | Все эффекты `:hover` и `:active` происходят **плавно и красиво**, без резких скачков. |

### 📐 Ровная сетка для кнопок (Слайд II/1 и Слайд III)
Чтобы 11 кнопок предметов (и 4 кнопки выбора экзамена) встали аккуратными рядами, как на твоём рисунке, изучи 3 свойства для контейнера `<div>` (например, `.grid-subjects`):
- **`display: grid;`** — включает режим сетки внутри контейнера.
- **`grid-template-columns: repeat(4, 1fr);`** — раскладывает кнопки ровно в **4 равные колонки** (а если написать `repeat(2, 1fr)` — получится сетка **2×2** для Слайда II/1!).
- **`gap: 10px;`** — делает одинаковые аккуратные промежутки между всеми кнопками сетки.

## 3. Памятка: как запустить `localhost`, проверить ветку `dev` и запушить код

### Шаг А. Запуск локального сайта (`localhost:8000`)
1. Открой **VS Code** и верхнее меню **Terminal → New Terminal**.
2. Посмотри на путь в терминале: если там написано `C:\Projects\yandex_course>`, зайди в папку проекта командой:
   ```powershell
   cd AI-agent-for-OGE_and_EGE
   ```
3. Запусти локальный сервер (пишем именно **`python`**, а не `py`!):
   ```powershell

   ```

   *(Если после `Ctrl + S` в браузере не видно изменений — нажми `Ctrl + F5` или открой вкладку Инкогнито `Ctrl + Shift + N`.)*


## 4. Шпаргалка по тегам HTML (что за что отвечает)

HTML — это «скелет» страницы. Почти каждый тег открывается `<тег>` и закрывается `</тег>`, а внутри лежит его содержимое. Вот главные теги, которые уже есть в твоём `index.html` и пригодятся дальше:

### 🧱 Каркас страницы
| Тег | Что это такое | Зачем нужен |
|---|---|---|
| `<!DOCTYPE html>` и `<html>` | Обёртка всего документа. | Сообщает браузеру: «Это современная веб-страница (HTML5)». |
| `<head> ... </head>` | «Голова» страницы (невидима на экране). | Сюда подключаем шрифты, стили `style.css`, движок **PyScript** и заголовок вкладки `<title>`. |
| `<title> ... </title>` | Название вкладки браузера. | Текст, который видно наверху на вкладке рядом с иконкой. |
| `<body> ... </body>` | «Тело» страницы. | Всё, что пользователь реально видит на экране (слайды, тексты, кнопки). |
| `<link rel="stylesheet" href="...">` | Подключение файла стилей (пишется в `<head>`). | Привязывает к странице наш `style.css`. |
| `<script type="py" src="./main.py">` | Подключение Python-кода. | Запускает наш `main.py` в браузере. **Важно:** всегда ставим его в самом низу `<body>` (прямо перед `</body>`), чтобы к моменту запуска все кнопки на странице уже существовали! |

### 📦 Блоки, текст и кнопки (внутри `<body>`)
| Тег | Что это такое | Зачем нужен |
|---|---|---|
| `<section> ... </section>` | Самостоятельный смысловой экран / раздел. | В нашем проекте каждый `<section>` — это отдельный **слайд** (Слайд I, Слайд II/1, Слайд III…). |
| `<div> ... </div>` | Универсальная «коробка» для группировки элементов. | В него удобно складывать кнопки, чтобы выстроить их сеткой (например, `<div class="grid-subjects">`). |
| `<h1>`, `<h2>`, `<h3>` | Заголовки разного размера (`h1` — самый главный, `h3` — поменьше). | Оформляют названия слайдов и задач (как `#`, `##`, `###` в Markdown!). |
| `<p> ... </p>` | Обычный абзац текста. | Приветствия, условия задач, подсказки и сообщения. |
| `<span> ... </span>` | Короткий строчный фрагмент текста (не переносит строку). | Удобно, когда нужно выделить или поменять через Python только кусочек строки (например, цифры таймера `00:00`). |
| `<button> ... </button>` | Интерактивная кнопка. | То, на что пользователь нажимает (переходы между слайдами, выбор предмета, проверка ответа). |
| `<input type="text">` | Поле для ввода текста (закрывающий тег не нужен!). | Пригодится на Слайде IV, чтобы ученик вписывал ответ на задачу. |
| `<!-- комментарий -->` | Подсказка для себя в коде. | Браузер полностью её игнорирует — удобно подписывать, где начинается каждый слайд. |

### 🏷 Главные атрибуты внутри тегов
Атрибуты пишутся внутри открывающего тега (например, `<button id="btn-start" class="btn">`):
- **`id="..."`** — **уникальное имя** конкретного элемента (не должно повторяться на странице!). В Python ищем по `#имя`.
- **`class="..."`** — **группа / стиль** (один и тот же класс можно дать хоть 11 кнопкам сразу!). В CSS и Python ищем по `.имя`.
- **`data-...="..."`** — **своя «бирка»** (например, `data-subject="math"`), чтобы хранить на кнопке служебную подсказку для Python.
