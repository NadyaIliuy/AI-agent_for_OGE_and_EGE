# Тренажёр ОГЭ (Python + PyScript)

Веб-приложение для подготовки к ОГЭ на базе открытого банка заданий ФИПИ.  
Весь код на Python выполняется прямо в браузере пользователя без сервера, сайт размещён на GitHub Pages.

## Паспорт проекта
- **Автор (разработка):** Надя Ильющенко
- **Наставник:** Николай Шипигузов
- **Цель проекта:** создать удобный тренажёр с проверкой ответов разных форматов ОГЭ, сохранением прогресса в браузере, генератором полного варианта (30 заданий) и ИИ-разбором сложных заданий.
- **Стек:** Python (PyScript 2024.11.1), HTML5, CSS3, JSON, `localStorage`, GitHub Pages.
